codecall · for Codex & Claude Code

codecall teaches you the code you just wrote.

After you (or your AI assistant) finish building something, codecall turns that work into a quick, friendly quiz — so you actually understand what was built, not just that it works.

It runs inside Codex or Claude Code, the AI coding tools you already use. No extra app, no signup, no API key.
