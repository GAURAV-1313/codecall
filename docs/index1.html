codecall · for Codex & Claude Code

codecall teaches you the code you just wrote.

After you (or your AI assistant) finish building something, codecall turns that work into a quick, friendly quiz — so you actually understand what was built, not just that it works.

It runs inside Codex or Claude Code, the AI coding tools you already use. No extra app, no signup, no API key.

Grounded in your code

codecall doesn’t run a generic curriculum. It looks at what was actually built this session — the files touched, the pattern used — and teaches the ideas behind it using your real code as the example, then checks your understanding with a couple of quick questions.

You’re always in control

It only starts when you choose Start Learning, and you can Skip every time. If you installed the plugin, a small local check just reminds the agent to consider offering a session — it never decides for you, makes no network calls, and can’t edit files or run other commands on its own.

Three ways in

Pick the install that fits your setup

Same product either way — these just differ in how codecall gets offered to you automatically.

Either tool, the simple way

Installs codecall for both Codex and Claude Code at once. Type $codecall in Codex, /codecall in Claude Code. Doesn’t include the automatic-offer check, since it isn’t installed as a plugin.

$npm install -g codecall

Codex plugin

Adds the plugin-store install path plus a small local script that reminds Codex to consider offering a session after something meaningful happens.

$codex plugin marketplace add https://github.com/GAURAV-1313/codecall
$codex plugin add codecall@codecall

Claude Code plugin

Same automatic-offer check, installed as a Claude Code plugin. Some of the read-only “is this worth teaching” work runs in an isolated helper so it doesn’t clutter your main conversation.

>/plugin marketplace add https://github.com/GAURAV-1313/codecall
>/plugin install codecall@codecall
